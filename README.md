# ProjectPilot AI 🚀

## AI-Powered Software Project Development Assistance Platform

ProjectPilot AI is an intelligent project development assistance platform designed to help students and developers plan, organize, manage, and develop software projects with the support of Artificial Intelligence.

The platform combines project management features with an AI-powered assistant called **MASTER AI**, helping users with project ideas, task management, notes, project organization, and development guidance.

---

## ✨ Features

- 🤖 MASTER AI Assistant
- 📁 Project Management
- ✅ Task Management
- 📝 Notes Management
- 📊 Project Dashboard
- 👤 User Profile
- ⚙️ Application Settings
- 🔐 User Authentication
- 🛡️ Protected Routes
- 👨‍💼 Admin Management
- 💬 AI-powered Chat
- 🎨 Modern Dark UI
- 💡 Project Development Assistance

---

## 🤖 MASTER AI

MASTER AI is the intelligent assistant integrated into ProjectPilot AI.

It can assist users with:

- Project planning
- Project ideas
- Development guidance
- Task-related assistance
- Programming-related questions
- Project organization
- General software development support

The AI service is designed to work with a locally running **Ollama** model.
